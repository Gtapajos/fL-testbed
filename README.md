# Testbed para Federated Learning

Este projeto é um testbed para simular cenários de redes adversas em aplicações de Federated Learning. Ele utiliza Flower para coordenar o treinamento federado e Pumba para simular condições de rede adversas.

As tecnologias utilizadas incluem Python, Docker Compose, Flower, Pumba, NumPy, Pandas, Matplotlib e PyTorch.

## Dataset

Sonawani, Shilpa; Patil, Kailas (2021), “Delhi Multi-Site Air-Quality Data Set”, Mendeley Data, V1, doi: 10.17632/bzhzr9b64v.1.
